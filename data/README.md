# Dataset

This project uses the Consumer Complaint Database published by the Consumer Financial Protection Bureau (CFPB).

The raw complaint dataset is not included in this repository.

## Source

The dataset can be downloaded from the CFPB Consumer Complaint Database:

https://www.consumerfinance.gov/data-research/consumer-complaints/

## Setup

After downloading the dataset, place the CSV file in this `data/` directory.

The notebook expects the dataset at:

```text
data/complaints-2026-08-27_02-24.csv
